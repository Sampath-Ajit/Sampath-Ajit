## What I'm building here

A public record of a security career built on evidence, not certificates. Every repository here is either a working security tool, a deliberately insecure app used for practice, or a writeup showing the method: **hypothesis → test → evidence → impact → fix**.

The rules I train by:
1. **Method over tool** — understand why a technique works before automating it.
2. **Every engagement ends in an artifact** — a writeup or a reusable tool.
3. **Manual validation** — a scanner finding is a lead, not a finding.
